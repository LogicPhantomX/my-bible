MY BIBLE — Rehoboth download page

Files:
- index.html — the landing page
- styles.css — page styles
- assets/ — logo and favicon
- my-bible-rehoboth.apk — installable Android debug APK

To publish:
1. Import this folder in Vercel, or drag and drop it in the Vercel dashboard.
2. Use the "Other" framework preset and keep the output directory as the project root.
3. Keep the APK in the same folder as index.html.
4. Open the published page and tap “Download APK”.

The APK is signed with the standard Android debug key and is intended for direct installation/testing on Android 7.0+ devices.
